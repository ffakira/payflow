# PayFlow

Sistema de processamento financeiro desenvolvido com Java e Spring Boot, com foco em integridade de dados, consistência transacional, modelagem de domínio e arquitetura hexagonal.

O projeto tem como objetivo construir uma base sólida para operações financeiras, separando as regras de negócio da infraestrutura e estabelecendo mecanismos de persistência confiáveis para contas e transações contábeis.

## Objetivos do projeto

* Desenvolver uma arquitetura organizada por domínios de negócio.
* Aplicar princípios de Domain-Drive Design (DDD) e Arquitetura Hexagonal.
* Garantir a integridade das operações financeiras por meio de transações e restrições no banco de dados.
* Implementar testes unitários e de integração para validar as regras de negócio e a persistência.
* Explorar recursos modernos do Java e do ecossistema Spring.
* Estabelecer uma base evolutiva para funcionalidades financeiras futuras.
